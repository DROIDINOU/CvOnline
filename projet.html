SAAS Moniteur Alertes

Surveillance automatique du Moniteur Belge avec alertes en temps réel.

Présentation

Moniteur Alertes est une application web complète permettant de surveiller automatiquement les publications du Moniteur Belge liées à la solvabilité des entreprises. Le système repose sur un moteur de scraping Python robuste (regex + fallback BCE) et génère des alertes en temps réel pour les utilisateurs. L’ensemble du projet a été conçu, développé et déployé en autonomie : architecture backend, sécurité serveur, pipeline d’automatisation et interface publique.

Fonctionnalités principales

  • Scraping Python avancé du Moniteur belge (regex + fallback automatique vers la BCE)
  • Détection intelligente des publications liées à la solvabilité et aux procédures judiciaires
  • Système d’alertes email en temps réel (pipeline automatisé + gestion des erreurs)
  • Tableau de bord utilisateur : suivi des entreprises, historique, filtres, statut des alertes
  • Gestion complète des utilisateurs : inscription, authentification, rôles, préférences
  • Intégration Teamleader validée (lecture contacts/entreprises, synchronisation automatique)
  • Intégration Odoo (synchronisation des partenaires et automatisation des vérifications)
  • Interface publique moderne en React / Next.js, responsive et accessible

Stack technique

  • Backend : Python (scraping, regex), tâches planifiées (cron), gestion des erreurs réseau, logs, monitoring
  • Infrastructure : Serveur Linux sur DigitalOcean, configuration manuelle, sécurisation SSH, firewall UFW, reverse proxy Nginx, Gunicorn, services systemd
  • Frontend : React + Next.js (déploiement sur Vercel)
  • Automatisation : Pipeline complet : scraping → analyse → filtrage → alertes email ou intégrations ERP et CMS
  • Intégrations externes : Teamleader API (OAuth, synchronisation), Odoo API
  • Déploiement & maintenance : supervision, logs, webhooks, mises à jour serveur, optimisation des performances
